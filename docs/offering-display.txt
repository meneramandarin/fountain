OFFERING DISPLAY RESOLUTION

Raw offerings remain intact in fountain.offerings. Current display suppressions
are stored in fountain.offering_display_suppressions with a reason, winning
offering, rule version, and evidence. Suppressions can be deactivated by a later
recomputation; offerings are never deleted or remapped by this process.

Rules

1. Normalized same-term offerings with the same price/currency are collapsed to
   the strongest source. Differently priced copies remain visible and are
   reported as price conflicts.
2. An unpriced exact duplicate is suppressed when a priced copy exists.
3. Distinct services sharing a canonical treatment remain visible. A shared
   treatment family is never evidence that two clinic menu rows are duplicates.

Preview all locations:

  npm run offerings:display -- --dry-run

Apply all locations:

  npm run offerings:display -- --apply

Recompute one location:

  npm run offerings:display -- --location-id 63 --apply

The menu_extract task recomputes display resolution for a location after a
successful serving write. The directory detail query excludes active
suppressions.
